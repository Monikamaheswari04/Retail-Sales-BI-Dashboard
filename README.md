# 📊 Retail Sales BI Dashboard | Python • Pandas • Plotly • Dash

An interactive, fully responsive **Business Intelligence Dashboard** built using **Python, Pandas, Plotly, and Dash** to analyze retail sales data.  
Designed in a **Tableau-style layout** with sidebar filters, KPI cards, and dynamic visualizations.

This project demonstrates real-world **data analysis, dashboarding, and business insight generation** skills.

---

## 🚀 Key Features

- 📌 **Sidebar Filters** (Year, Region, Category)
- 📈 **Interactive Visualizations**
  - Sales by Category & Sub-Category  
  - Sales by Region & Segment  
  - Top 10 Products & Top 10 States  
  - Year-wise & Month-wise Trends  
  - Sales Heatmap (Month vs Year)
- 💡 **KPI Cards**
  - Total Sales  
  - Top Product  
  - Top Region  
- 🎨 **Modern UI**
  - Glassmorphism effect  
  - Hover animations  
  - Icons on KPI cards  
  - Dark professional theme  
- 📱 **Fully Responsive** (Desktop, Tablet, Mobile)
- ⚡ **Real-time Updates using Dash Callbacks**

---

## 🛠️ Tech Stack

- **Python 3**
- **Pandas** – Data cleaning & analysis  
- **Plotly Express** – Interactive charts  
- **Dash** – Web dashboard framework  
- **HTML/CSS (Dash components)** – Layout & styling


```bash

```
